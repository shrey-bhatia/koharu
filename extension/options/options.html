CSS Class API

Userscripts (ViolentMonkey, etc.) can mark images for auto-translation by adding the CSS class koharu-translate to any <img> element or its parent container. 

// ViolentMonkey example
document.querySelectorAll('.manga-page img').forEach(img => {
  img.classList.add('koharu-translate');
});
